# Atividade – Design Pattern Adapter

Nome: Luciano Giraldi Filho | RA: 22228890-2

Este projeto implementa o padrão de projeto **Adapter** usando Node.js, convertendo dados de um arquivo CSV em objetos da classe `Pessoa`.

## Estrutura

- `Pessoa.js` – Classe que representa uma pessoa com nome, idade e email.
- `PessoaCsvAdapter.js` – Adaptador que lê o arquivo CSV e retorna uma lista de pessoas.
- `pessoas.csv` – Arquivo com os dados das pessoas.
- `main.js` – Classe de teste que usa o adaptador para listar os dados.

## Como executar

1. Instale o Node.js;
2. Execute: node main.js
